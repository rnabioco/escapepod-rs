- **`escpod classify` holds ~1/3 less memory (394 -> 270 MB anonymous peak on a 70k-read BAM, ~1.8 KB/read, ~100 GB at 57 M reads), and counts each read's orientation vote once (#479).** `AnchoredRead` kept the move-table map as eight bytes per base for every read in the BAM; it now keeps the move table bit-packed (`AnchoredRead::moves`, `PackedMoves`) and derives `seq_to_sig()` where it is used. The map is identical, so calls are byte-identical (`cl` tags and TSV, three interleaved reps). The frame vote used to be cast per BAM record, so a read with several anchored alignments voted more than once, and for a frame its kept alignment might not share; it is now tallied after the best-mapq dedup. On the real run the votes are unchanged (66943 reversed / 0 time), since secondary and supplementary records were already skipped. **Breaking for library callers:** `AnchoredRead::seq_to_sig` is now a method, and the field is `moves`.
