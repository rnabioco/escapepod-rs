- **VBZ encode is 4-13% faster per chunk, and the Python `Writer` no longer holds the GIL while it compresses.** `compress_signal` built a fresh ZSTD encoder (context, tables, 32 KB buffer) and a fresh SVB16 buffer for every chunk; it now reuses a thread-local one-shot compressor and scratch (13% at 1k/10k samples, 4% at 100k). Compressed bytes are unchanged (pinned against the old streaming encoder over many lengths). `Writer::add_reads` compresses a batch's chunks in parallel and writes them in input order, byte-identical to an `add_read` loop; the Python `Writer.add_read`/`add_read_data`/`add_reads` release the GIL around it.
