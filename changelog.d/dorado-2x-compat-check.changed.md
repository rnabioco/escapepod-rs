- **dorado pin bumped 1.4.0 -> 2.1.2, and a dorado-vs-escpod POD5 compatibility check added (`benchmarks/dorado-compat/`).** The check runs `merge`/`filter`/`subset`/`demux split` over real short-last-batch inputs, basecalls each with dorado, and compares BAM parent read ids to the POD5; dorado 2.1.2 reads every output. Its negative control (a hand-built non-uniform signal table) shows dorado 2.1.2 exits 0 while silently dropping 704 of 1865 reads, so an exit code alone is not a compatibility check. Replaces `tests/test_dorado_compat.sh`, which called `dorado summary` on a POD5 (it takes a BAM).
