- **`escpod classify --device gpu` on a `waveform_model` bundle keeps the GPU ~92% busy (was 62-73%) and scores a 55k-read set ~25% faster.** The single GPU-submitting thread packed each 128-read group's three input tensors and re-scored every 64th group on the CPU for the parity check, both while the GPU waited. Packing now happens on the producer side, in parallel on the rayon pool (`WaveformNetGpu::pack` / `logits_packed`), and the parity re-score runs as a rayon task. The bytes fed to the graph, the parity schedule and the batching rule (`expand_instance_norm`) are unchanged, so every call, `cl` tag and the recorded worst `|dP|` are identical to before.
